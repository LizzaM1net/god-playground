Installation Complete

God Playground is installed under /opt/pluginplayground, and the godmfi daemon (com.pluginplayground.godmfi) is already running.

During install it generated your god signing identity, god-signed fangs, and patched amfid. It restarts at every boot — godmfi-launch re-patches a fresh amfid and brings fangs back up.

Grant private entitlements to your own code

# 1. God-sign your binary or .app bundle (godmfi is on your PATH; it prompts for admin)
godmfi sign /path/to/MyTool

# 2. Run it. amfid is already patched by the godmfi daemon, so your signature
#    is verified against the pinned cert and MyTool loads with its entitlements.
/path/to/MyTool

Check status

pgrep -x fangs && echo "godmfi daemon running"
godmfi status          # identity + pin
godmfi test            # run the amfi verdict-matrix checks
# logs: /var/log/pluginplayground/godmfi.log

To remove everything (daemon, identity, and files) and return amfid to stock, run uninstall.sh from the source tree.

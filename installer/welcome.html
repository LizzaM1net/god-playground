God Playground

God Playground is an open-source macOS Apple-Silicon toolkit for security research into code signing and entitlements. It is a fork of the Plugin Playground runtime-tweak system, built around godmfi.

godmfi

godmfi is a cert-pinned amfid verdict override. You generate a private "god" code-signing identity; godmfi pins that certificate and makes amfid accept binaries signed with it — and only those — so they load with whatever Apple-private entitlements they embed.

The gate is cryptographic: godmfi verifies the code signature against the pinned certificate, so possession of the private key — not mere presence of the public cert — is what grants god status.

Includes

tweaks/godmfi.dylibThe cert-pinned amfid verdict override
bin/fangsPersistent injector — keeps amfid patched across respawns
bin/godmfi-launchBoot bootstrap — patches amfid, then starts fangs
tools/godmfiCreate the god identity and sign your binaries
Configurator appGUI for managing tweaks (in /Applications)

Requires System Integrity Protection (SIP) to be disabled. This is a research tool that patches a system daemon; install it only on a machine you own and have deliberately configured for this.
